# مساعد ريادة الذكي — مكالمات + واتساب

نظام يرد على المكالمات الهاتفية بالصوت ويرد على واتساب، مبني على Claude وTwilio.

## اللي يسويه النظام

- 📞 يرد على المكالمات، يتكلم بالعربية، ويفهم طلب المتصل
- 💬 يرد على رسائل واتساب العملاء تلقائياً
- 🔔 يرسل لك (المالك) ملخص كل مكالمة، وإشعار بكل رسالة عميل، عبر نفس رقم الواتساب
- 🗣️ ترسل أنت رسالة لنفس الرقم (من رقمك المسجّل كـ "مالك") ويتعامل معها كمساعدك الشخصي

---

## الخطوة 1: إنشاء حساب Twilio

1. روح لـ [twilio.com](https://www.twilio.com/try-twilio) وسوّي حساب مجاني
2. من لوحة التحكم (Console) انسخ:
   - **Account SID**
   - **Auth Token**
3. هذي القيم تحطها بملف `.env` (شوف الخطوة 4)

## الخطوة 2: شراء رقم هاتف للمكالمات

1. من القائمة الجانبية: **Phone Numbers → Buy a Number**
2. اختر رقم يدعم **Voice** (والدولة اللي تبيها)
3. بعد الشراء، افتح إعدادات الرقم:
   - **A Call Comes In** → Webhook → حط: `https://your-server.com/voice` (Method: POST)
   - **Call Status Changes** → حط: `https://your-server.com/voice/status` (Method: POST)

> ملاحظة: أرقام Twilio التجريبية (Trial) فيها قيود على الاتصال بأرقام غير موثقة. لاستخدام حقيقي مع عملاء، تحتاج ترقية الحساب (Upgrade) بإضافة وسيلة دفع.

## الخطوة 3: تفعيل واتساب

**للتجربة السريعة (Sandbox، مجاني):**
1. من القائمة: **Messaging → Try it out → Send a WhatsApp message**
2. اتبع التعليمات لربط رقمك الشخصي بالـ Sandbox (ترسل كود معيّن للرقم التجريبي)
3. رقم الـ Sandbox عادة: `whatsapp:+14155238886`
4. من إعدادات Sandbox، حط **When a message comes in**: `https://your-server.com/whatsapp`

**للاستخدام الفعلي مع عملاء حقيقيين (لازم قبل الإطلاق):**
1. تحتاج **WhatsApp Business Account** موثق عبر Meta (يتم من نفس لوحة Twilio: **Messaging → Senders → WhatsApp senders**)
2. يتطلب رقم هاتف مخصص + معلومات نشاطك التجاري + مراجعة من Meta (تاخذ أيام)
3. بعد الموافقة، تحصل رقم واتساب رسمي بدل الـ Sandbox

## الخطوة 4: إعداد المشروع

```bash
# فك ضغط الملفات ثم:
npm install
cp .env.example .env
```

افتح `.env` واملأ:
- `ANTHROPIC_API_KEY` — من [console.anthropic.com](https://console.anthropic.com)
- `TWILIO_ACCOUNT_SID` و `TWILIO_AUTH_TOKEN` — من خطوة 1
- `TWILIO_PHONE_NUMBER` — رقمك من خطوة 2
- `TWILIO_WHATSAPP_NUMBER` — رقم الواتساب (Sandbox أو الرسمي)
- `OWNER_WHATSAPP_NUMBER` — رقمك أنت بصيغة `whatsapp:+9665xxxxxxxx` (نفس الرقم اللي ربطته بالـ Sandbox في خطوة 3)

## الخطوة 5: تعديل معلومات الشركة

افتح ملف `knowledge-base.js` وعدّل `KNOWLEDGE_BASE` بمعلومات شركة ريادة الحقيقية (الخدمات، الأسعار، ساعات العمل، سياسة الاسترجاع...). كل ما كانت المعلومات دقيقة، كل ما كانت ردود المساعد أدق.

## الخطوة 6: النشر على السيرفر

```bash
npm start
```

لازم رابط السيرفر يكون **HTTPS عام** (يوصله Twilio من الإنترنت) — لأنك ذكرت إنك تملك سيرفر (Render/AWS/VPS)، انشر المشروع هناك بنفس طريقتك المعتادة، وتأكد المنفذ (PORT) مفتوح.

للتجربة المحلية قبل النشر النهائي، تقدر تستخدم [ngrok](https://ngrok.com) عشان تحصل رابط عام مؤقت يوصل لجهازك.

## الخطوة 7: الربط النهائي

بعد ما يشتغل السيرفر على رابط حقيقي:
1. حدّث Webhooks في Twilio (خطوة 2 و 3) بالرابط الفعلي بدل `your-server.com`
2. اتصل على رقمك للتجربة
3. أرسل رسالة واتساب لرقم الـ Sandbox/الرقم الرسمي للتجربة

---

## قيود النسخة الحالية (MVP) وإمكانية التطوير

- **الذاكرة مؤقتة**: تُمسح المحادثات عند إعادة تشغيل السيرفر. للإنتاج، أضف قاعدة بيانات (Redis أو Postgres) بدل `Map()` في `server.js`.
- **"التنفيذ" عبر واتساب حالياً محادثة فقط**: المساعد يرد ويقترح، لكنه لا يستطيع تنفيذ أفعال حقيقية (إرسال إيميل، حجز موعد...) إلا إذا أضفت له أدوات (function calling) مربوطة بأنظمتك — يمكن إضافتها لاحقاً باستخدام `tools` في Anthropic SDK.
- **الصوت**: يستخدم أصوات Twilio/Polly الجاهزة للعربية. لصوت أكثر طبيعية، يمكن استبداله بخدمة مثل ElevenLabs.
- **الأمان**: تأكد من تفعيل [التحقق من توقيع Twilio](https://www.twilio.com/docs/usage/webhooks/webhooks-security) على كل Webhook قبل الإطلاق الفعلي لمنع طلبات مزيفة.
